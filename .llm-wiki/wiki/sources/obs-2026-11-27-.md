# ⭐ Observation: 改道卡必须是会话条目而非自定义消息

pi-pretty-task 的改道通知（ADR-0020）最初是一行 `ctx.ui.notify`，下次重画就消失；用户要求"看得见、留得住"。可行面只有 `pi.appendEntry<T>(customType, data)` + `pi.registerEntryRenderer<T>`：写 `CustomEntry`（落盘、重载时 interactive-mode 的两条路径都会 `addCustomEntryToChat` 重画、按构造不进模型上下文）。`pi.sendMessage` 的选项只有 `triggerTurn`/`deliverAs`，没有 `excludeFromContext`，发 custom message 会与工具返回重复进模型上下文。宿主 `components/custom-entry.js` 的 `CustomEntryComponent.rebuild()` 只 addChild(Spacer(1)) 再挂渲染器返回值，不套 Box——带底色的卡必须由渲染器自己 `new Box(1, 1, (t) => theme.bg("toolPendingBg", t))`；`components/custom-message.js` 那层 Box 是消息专用。实跑验证：`{"customType":"task-detached","data":{"id":"bg-uxxlb","trigger":"timeout","afterSeconds":120}}`，工具返回同一时刻给出 `it had held the front for 120s, so the foreground timeout moved it`。仓库 pi-pretty-task，提交 71bdd2f。
