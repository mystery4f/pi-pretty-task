# 面板用状态栏 + 浮层，不做常驻 widget

Task 列表（`process` 与 `loop` 两种 kind 混排在一张表）通过 `/tasks` 打开的浮层呈现，状态栏那一行从会话启动就存在（不必先打开过面板），浮层关闭后也保持这一行摘要。pi 提供了 `ctx.ui.setWidget`（编辑器上方常驻区），我们明确不用。

## Considered Options

- **常驻 widget**：任何时刻可见，但持续占用编辑器上方的高度，且与输入区争视觉焦点。
- **状态栏 + 浮层（采用）**：平时零占位，需要时一屏看清。

## Consequences

- 状态栏那一行必须包含“有几个在跑、怎么打开面板”，否则用户会忘记面板存在。
- 无法在“不打开面板”的前提下看到命令 —— 这是刻意接受的代价：命令的本质信息量需要一屏空间。
